# Node Service Template

Use this template for new Node.js microservices.

## Expected Directories

- `src/bootstrap`
- `src/platform`
- `src/modules/<capability>/{http,application,domain,infrastructure,contracts}`
- `src/docs`
- `src/workers`
- `tests/{unit,integration,system}`

Copy this template, then rename `example` module to your first business capability.
